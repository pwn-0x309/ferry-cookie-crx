//the loop — grab / ferry / land

Three commands you never type, because two clicks do it.

01 · SOURCE TAB

$ferrycookie grab

On the logged-in site: one keystroke or one click. The page's cookies go to the dock and the clipboard — every host rewritten to localhost in flight.

02 · THE FERRY

$ferrycookie ferry --rewrite-hosts

A session-scoped envelope — no clipboard round-trip needed. Dialect sniffing on the way in: EditThisCookie v3, FC envelope, or Playwright addCookies.

03 · LOCALHOST

$ferrycookie land --mode=merge

A guarded write: diff screen, jar-verified report, snapshot taken first. The page reloads logged-in.

//safety — the part you were worried about

A tool that touches cookies should be the most conservative thing in your browser.

Every claim below is checkable in the repo — reviewable vanilla JS, no build step, no bundler. Click through; don't take a landing page's word for it.

zero egress

Nothing leaves the browser. No network calls with your data, no CDN, no remote code. The whole extension is reviewable vanilla JS.

storage.session only

All cookie-derived state dies with the browser. The only persistent setting is the Fast-mode boolean.

one-click undo

Every landing takes a snapshot first. The report is jar-verified — what it says landed is what landed.

zero telemetry

No analytics, no counters, no phone-home. Values render via textContent only — no injected HTML.
